Лист персонажа Long Story Short поддерживает создание собственных заклинаний и импорт готовых в формате Foundry VTT.

Оба варианта доступны в [Гримуаре](/spells/) и подчиняются установленным [лимитам](/doc/main/limits/).

## Создание заклинаний

В [Гримуаре](/spells/) нажмите кнопку «Создать заклинание» и заполните все необходимые поля.

### Переменные

Поле «Кость» в разделе «Эффект» поддерживает две особых переменных:

- **@mod** — заклинательная характеристика
- **@item.level**  — уровень ячейки, которой сотворено заклинание

Например, заклинание «Лечащее слово» использует такую формулу для бросков:

```
1d4 + @mod
```

## Импорт заклинаний

В [Гримуаре](/spells/) нажмите кнопку «.json» и затем «Загрузить .json». Во всплывающем окне можно выбрать подходящий файл, а затем конкретные заклинания, которые требуется добавить в Гримуар.

### Где брать готовые заклинания?

Формат заклинаний основан на формате виртуального стола Foundry, поэтому подойдёт любой источник, где можно взять заклинания для Foundry.

## Экспорт заклинаний

В [Гримуаре](/spells/) нажмите кнопку «.json» и затем «Скачать .json». На устройство будет сохранён файл со всеми заклинаниями, которые были вами созданы/импортированы. Файл можно использовать для последующего импорта заклинаний.
