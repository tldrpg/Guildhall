# Каталог виджетов

Виджеты — это строительные блоки шаблона. Каждый предназначен для своего типа данных или действий. Ниже — что когда брать; подробности по каждому виджету на отдельной странице.

## Виджеты палитры

| Виджет | Когда брать |
|---|---|
| **[Модификатор](widgets/mod.md)** | Числовые бонусы и характеристики, кнопки бросков. Значение считается формулой, а не вводится игроком. |
| **[Текстовое поле](widgets/input.md)** | Любой текст, который вводит игрок: имя, снаряжение, заметки. |
| **[Подпись](widgets/label.md)** | Неизменяемый или вычисляемый текст: заголовки, сводки, текстовые кнопки. |
| **[Чекбокс](widgets/checkbox.md)** | Одно состояние да/нет: владение навыком, статус, наличие предмета. |
| **[Счётчик (поле)](widgets/counter.md)** | Числа, которые меняются в игре: HP, опыт, золото. С необязательным максимумом. |
| **[Счётчик (чекбоксы)](widgets/counter-dots.md)** | То же число, показанное ячейками: заклинания, усталость, удача. |
| **[Контейнер](widgets/container.md)** | Группировка виджетов и раскладка их в ряд или столбец. |

> Прежний виджет **«Текстовый блок»** устарел и убран из палитры: многострочность теперь включается тоглом «Многострочный» в [Текстовом поле](widgets/input.md). Уже созданные «Текстовые блоки» продолжают работать.

Общие для всех виджетов свойства внешнего вида описаны отдельно: [Оформление виджетов](widgets/styling.md).

## Настройки виджета
Клик по виджету в редакторе открывает панель настроек с тремя вкладками:

1.  **Данные** — значения полей, их подписи и служебные тоглы (см. ниже).
2.  **Связи** — какие виджеты привязаны к этому. Без привязки формула не увидит чужую переменную.
3.  **Стили** — внешний вид: [Оформление виджетов](widgets/styling.md).

## Поля и переменные
У каждого виджета свой набор полей — они перечислены на его странице вместе с именами, под которыми поле доступно в формулах. Общие правила:

*   **Собственные поля** доступны без всяких настроек через префикс `local-`: `[local-modifier]`, `[local-current]`.
*   **Чужие поля** видны, только если виджет привязан на вкладке **Связи** *и* поле помечено как **публичное** (иконка глаза рядом с полем, тултип «Публичная переменная»). Приватные поля не видны даже привязанным виджетам.
*   **Алиас** — понятное имя поля для формул: вместо `modifier-663988958975` пишете `[str_mod]`. Задаётся там же, на вкладке «Данные».
*   **Тогл «Редактируется игроком»** (карандаш) определяет, может ли игрок менять поле на листе. Выключенное поле правит только автор шаблона в редакторе.

Подробнее: [Формулы и переменные](formulas-and-variables.md).

## Действие по клику
Любой подходящий виджет можно превратить в кнопку: в режиме игры клик по всей его площади запускает заданное действие. Действие выбирается на вкладке **Данные** параметром **«Действие по клику»**:
*   **Нет** — клик ничего не делает (по умолчанию).
*   **Бросок** — по клику кидается **«Формула броска»**. Формула поддерживает кости, переменные и условия `if()` (см. [Нотация формул](notation.md)).

Под полем формулы переключатель **«Использование дайсницы»** задаёт, что именно происходит по клику:
*   **Бросок** — формула кидается сразу;
*   **Композиция** — клик собирает общий бросок из нескольких виджетов, который кидается один раз (см. [Композиция](formulas-and-variables.md#композиция-бросок-из-нескольких-виджетов)).

Действие по клику доступно виджетам [Текстовое поле](widgets/input.md), [Подпись](widgets/label.md) и [Модификатор](widgets/mod.md). У «Модификатора» бросок по клику включён по умолчанию.

Когда действие включено, весь виджет работает как кнопка — собственная интерактивность содержимого отключается, и значения правятся только через настройки.

Смотрите далее: [Формулы и переменные](formulas-and-variables.md).
