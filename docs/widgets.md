# Каталог виджетов

Виджеты — это строительные блоки вашего шаблона. Каждый виджет предназначен для определённого типа данных или действий.

## Основные виджеты

### Модификатор (Mod)
Виджет для числовых бонусов и штрафов. Показывает одно значение, а по клику кидает другое — формулу броска.
*   **Применение**. Модификаторы характеристик (Сила, Ловкость), бонусы мастерства.
*   **Особенности**. Умеет автоматически добавлять знак `+` перед положительными числами (настраивается в Стилях). Бросок по клику включён по умолчанию (см. [Действие по клику](#действие-по-клику)).

### Текстовое поле (Input)
Используется для ввода текстовой информации — от коротких строк до длинных заметок.
*   **Применение**. Имя, класс, предыстория, способности, заметки.
*   **Особенности**. Тогл **«Многострочный»** переключает поведение: в однострочном режиме длинный текст уходит за край, в многострочном — переносится на новую строку. Поле можно сделать только для чтения тоглом **«Редактируется игроком»**.

> Прежний виджет **«Текстовый блок» (Textarea)** устарел и убран из палитры: многострочность теперь включается тоглом «Многострочный» в «Текстовом поле». Уже созданные «Текстовые блоки» продолжают работать.

### Подпись (Label)
Неизменяемый текст для оформления листа.
*   **Применение**. Заголовки секций, названия блоков, статичные подписи и пояснения.
*   **Особенности**. По умолчанию отображается плоско, без рамки и фона. Значение нельзя изменить в режиме игры. Поддерживает переменные и формулы — текст можно собирать из значений других виджетов. Может выполнять бросок по клику (см. [Действие по клику](#действие-по-клику)).

### Чекбокс (Checkbox)
Простой переключатель состояния («включено» или «выключено»).
*   **Применение**. Владение навыком, наличие предмета.

### Счётчик (поле)
Предназначен для числовых значений, которые часто меняются.
*   **Применение**. Очки здоровья (HP), опыт, текущий запас золота.
*   **Особенности**. Может отображать текущее и максимальное значение через разделитель (например, `10/25`).

### Счётчик (чекбоксы)
Отображает значение в виде чекбоксов.
*   **Применение**. Ячейки заклинаний, уровни усталости, пункты удачи.
*   **Особенности**. Наглядное отображение ограниченного ресурса. Тоглом **«Отображать номера»** ячейки можно пронумеровать, а «Начало нумерации» задаёт, с какого числа.

## Действие по клику
Любой подходящий виджет можно превратить в кнопку: в режиме игры клик по всей его площади запускает заданное действие. Действие выбирается автором шаблона в настройках виджета параметром **«Действие по клику»**:
*   **Нет** — клик ничего не делает (по умолчанию).
*   **Бросок** — по клику кидается **«Формула броска»**. Формула поддерживает кости, переменные и условия `if()` (см. [Нотация формул](/docs/notation.md)).

Действие по клику доступно для виджетов **Текстовое поле**, **Подпись** и **Модификатор**. У Модификатора бросок по клику включён по умолчанию.

Смотрите далее: [Формулы и переменные](/docs/formulas-and-variables.md).
