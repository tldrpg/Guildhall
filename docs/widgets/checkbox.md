# Чекбокс

Переключатель на два состояния: отмечен или нет. В формулах отмеченный чекбокс равен `1`, снятый — `0`. Размер по умолчанию — 2×1 клетка.

## Когда использовать
*   Владение навыком, наличие предмета, статус («отравлен», «вдохновлён»).
*   Флаг, который включает бонус в формуле через `if()`.
*   **Чем отличается от «Счётчика (чекбоксы)»**: тот хранит число отмеченных ячеек, этот — одно состояние.

## Поля (вкладка «Данные»)

| Поле в интерфейсе | Имя в формулах | Что хранит | По умолчанию |
|---|---|---|---|
| Подпись | `local-label` | Название чекбокса | `Чекбокс` |
| Значение | `local-checkbox` | Состояние: отмечен / снят | снят |

*   «Значение» публичное — привязав чекбокс через **Связи**, другие виджеты читают его по алиасу.
*   В формулах используйте числовое сравнение: `if([athletics_prof] == 1, [prof], 0)`.

## Оформление (вкладка «Стили»)
Группы: «Чекбокс», «Подпись». Уникальные свойства:
*   **Размер**, **Цвет фона**, **Цвет флажка** — внешний вид самой ячейки.
*   **Нестандартный флажок** — вместо галочки внутри рисуется прямоугольник со своим размером, цветом и обводкой.

Остальные свойства — общие: [Оформление виджетов](styling.md).

## Действие по клику
Не поддерживается: клик переключает состояние.

## Примеры
*   Владение навыком: алиас `athletics_prof`, а в модификаторе навыка — `1d20 + [str_mod] + if([athletics_prof] == 1, [prof], 0)`.
*   Состояние «Вдохновение»: алиас `blessed`, формула броска — `1d20 + if([blessed] == 1, 1d4, 0)`.

## Частые ошибки
*   **Условие не срабатывает** — в `if()` равенство пишется как `==`; одиночное `=` не работает.
*   **Чекбокс не читается из другого виджета** — он не привязан на вкладке «Связи» или у поля нет алиаса.
