# Счётчик (чекбоксы)

То же числовое значение, что и у обычного счётчика, но показанное рядом ячеек: закрашенные слева, пустые справа. Размер по умолчанию — 3×2 клетки.

## Когда использовать
*   Ячейки заклинаний, уровни усталости, пункты удачи, деления шкалы стресса.
*   Любой небольшой запас, который удобнее видеть, чем читать числом.
*   **Чем отличается от «Счётчика (поле)»**: значение то же, отличается только способ ввода. Для больших чисел (HP за сотню) ячейки неудобны.
*   **Чем отличается от «Чекбокса»**: чекбокс хранит одно состояние да/нет, здесь — число от нуля до максимума.

## Поля (вкладка «Данные»)

| Поле в интерфейсе | Имя в формулах | Что хранит | По умолчанию |
|---|---|---|---|
| Подпись | `local-label` | Название счётчика | `Счётчик` |
| Текущее значение | `local-current` | Сколько ячеек отмечено | `0` |
| Максимальное значение | `local-max` | Сколько всего ячеек | `6` |

*   Оба значения публичные — их можно читать из других виджетов через **Связи** и алиасы.
*   «Максимальное значение» задаёт количество ячеек и может быть формулой: `[level] + 1` — и число ячеек будет расти с уровнем.
*   У «Максимального значения» тогл «Редактируется игроком» по умолчанию выключен: количество ячеек — свойство шаблона, а не данные персонажа.

## Оформление (вкладка «Стили»)
Группы: «Общее», «Номера», «Чекбоксы», «Подпись». Уникальные свойства:
*   **Расстояние между чекбоксами** — отдельно по горизонтали и вертикали.
*   **Отображать номера** — нумерует ячейки; **Начало нумерации** задаёт, с какого числа считать (например с `1`, а не с `0`).
*   **Размер**, **Цвет фона** и **Цвет флажка** ячейки, её обводка.
*   **Нестандартный флажок** — вместо галочки внутри ячейки рисуется прямоугольник со своим размером, цветом и обводкой (так делают квадратные «залитые» ячейки).

Остальные свойства — общие: [Оформление виджетов](styling.md).

## Действие по клику
Не поддерживается: клик по ячейке меняет значение счётчика.

## Примеры
*   Ячейки заклинаний первого круга: максимум → `[spell_slots_1]`, «Отображать номера» включено.
*   Шкала стресса на 10 делений с нумерацией с единицы: максимум → `10`, «Начало нумерации» → `1`.

## Частые ошибки
*   **Ячеек больше, чем помещается** — увеличьте виджет в редакторе или уменьшите размер ячейки и расстояние между ними.
*   **Игрок не может отметить ячейку** — у «Текущего значения» выключен тогл «Редактируется игроком».
*   **Нумерация начинается с нуля** — задайте «Начало нумерации» = `1`.
