# Модификатор

Показывает одно число, а по клику кидает другое — формулу броска. Основной «кидающий» виджет: именно из него делают кнопки проверок и атак. Размер по умолчанию — 2×3 клетки.

## Когда использовать
*   Модификаторы характеристик (`+2` у Силы), бонус мастерства, класс защиты.
*   Любое значение, которое считается формулой, а не вводится игроком.
*   **Чем отличается от «Счётчика»**: значение «Модификатора» игрок чаще всего не правит прямо на листе — оно либо задано автором шаблона, либо вычисляется из других виджетов. Если нужно дать игроку быстро менять число во время игры (HP, золото), берите [Счётчик (поле)](counter.md).

## Поля (вкладка «Данные»)

| Поле в интерфейсе | Имя в формулах | Что хранит | По умолчанию |
|---|---|---|---|
| Модификатор | `local-modifier` | Отображаемое число или формула, которая его считает | `0` |
| Название | `local-label` | Подпись под значением | `Модификатор` |
| Действие по клику | — | Что происходит по клику в игре | Бросок |
| Формула | `local-expression` | Что именно кидается по клику | `1d20cs=20cf=1 + [local-modifier]` |

*   Поле «Модификатор» публичное — его значение доступно виджетам, которые привязали этот модификатор через **Связи**. Задайте ему алиас (например `str_mod`), чтобы ссылаться удобным именем.
*   В самом виджете к своим полям обращайтесь через `local-`: `[local-modifier]` работает без всяких связей.
*   «Формула» у «Модификатора» называется именно так; у остальных виджетов то же поле подписано «Формула броска».

## Оформление (вкладка «Стили»)
Группы: «Общее», «Модификатор», «Подпись». Уникальное свойство:
*   **Отображать плюс** — показывает `+2` вместо `2` у положительных значений. Отрицательные и так идут со знаком.

Остальные свойства — общие: [Оформление виджетов](styling.md).

## Действие по клику
У «Модификатора» бросок по клику включён по умолчанию — в отличие от других виджетов, где его нужно включать вручную. Формула поддерживает кости, переменные и условия; режим **«Композиция»** превращает клик в сборку общего броска из нескольких виджетов. См. [Действие по клику](../widgets.md#действие-по-клику).

## Примеры
*   Атака оружием: формула → `1d20 + [str_mod] + [prof] (Атака мечом)`.
*   Часть составного броска: формула → `+[local-modifier]` в режиме «Композиция».

## Частые ошибки
*   **Вместо числа `~error~`** — переменная не найдена: опечатка в алиасе или виджет не привязан на вкладке «Связи».
*   **Клик не кидает** — «Действие по клику» переключено в «Нет», либо вы проверяете в режиме редактирования шаблона, где клик выделяет виджет.
*   **Формула ссылается на `[modifier]` вместо `[local-modifier]`** — без префикса `local-` виджет ищет чужую переменную с таким алиасом.
