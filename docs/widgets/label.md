# Подпись

Неизменяемый текст для оформления листа. Игрок его не правит, но текст может собираться из значений других виджетов. Размер по умолчанию — 3×1 клетка.

## Когда использовать
*   Заголовки секций, названия блоков, пояснения к правилам.
*   Вычисляемые надписи: `Класс защиты: [ac]`, `Уровень [level] · [class]`.
*   Кнопка броска без числа — с текстом вроде «Инициатива».
*   **Чем отличается от «Текстового поля»**: подпись не редактируется на листе и по умолчанию рисуется плоско, без рамки и фона.

## Поля (вкладка «Данные»)

| Поле в интерфейсе | Имя в формулах | Что хранит | По умолчанию |
|---|---|---|---|
| Подпись | `local-label` | Текст; поддерживает переменные и формулы | `Подпись` |
| Действие по клику | — | Что происходит по клику в игре | Нет |
| Формула броска | `local-expression` | Что кидается по клику, если выбран «Бросок» | пусто |

*   Поле «Подпись» по умолчанию приватное: чтобы читать его из других виджетов, включите ему **«Публичная переменная»** (иконка глаза рядом с полем).
*   В тексте можно смешивать обычные слова и переменные: `Скорость: [speed] футов`.

## Оформление (вкладка «Стили»)
Группы: «Общее», «Подпись». Уникальных свойств нет — всё это общие размеры, отступы, фон, обводка и типографика: [Оформление виджетов](styling.md).

По умолчанию у подписи прозрачный фон и нулевая обводка, поэтому она выглядит как обычный текст на листе.

## Действие по клику
Поддерживается, по умолчанию выключено. Подпись — удобная «текстовая кнопка»: включите «Бросок» и впишите формулу. См. [Действие по клику](../widgets.md#действие-по-клику).

## Примеры
*   Заголовок секции: текст → `НАВЫКИ`, в стилях — Bold и верхний регистр.
*   Сводка: текст → `КЗ [ac] · Скорость [speed]`.
*   Кнопка инициативы: текст → `Инициатива`, действие → «Бросок», формула → `1d20 + [dex_mod] (Инициатива)`.

## Частые ошибки
*   **Переменная не подставляется** — виджет-источник не привязан на вкладке «Связи», либо у его поля не включена «Публичная переменная».
*   **Текст пропал** — формула вернула ошибку: у «Подписи» ненайденная переменная показывается пустотой, а не `~error~`.
*   **Игрок хочет править текст** — это не задача подписи, возьмите [Текстовое поле](input.md).
