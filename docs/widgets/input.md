# Текстовое поле

Поле для ввода текста — от имени персонажа до длинных заметок. Размер по умолчанию — 3×2 клетки.

## Когда использовать
*   Имя, класс, происхождение, снаряжение, заметки, описания способностей.
*   Значения, которые вводит игрок, а не считает формула.
*   **Чем отличается от «Подписи»**: текстовое поле игрок редактирует прямо на листе, подпись — нет.

> Прежний виджет **«Текстовый блок»** устарел и убран из палитры: многострочность теперь включается тоглом «Многострочный» в «Текстовом поле». Уже созданные «Текстовые блоки» продолжают работать.

## Поля (вкладка «Данные»)

| Поле в интерфейсе | Имя в формулах | Что хранит | По умолчанию |
|---|---|---|---|
| Подпись | `local-label` | Название поля | `Текстовая строка` |
| Текст | `local-input` | Введённый текст | пусто |
| Действие по клику | — | Что происходит по клику в игре | Нет |
| Формула броска | `local-expression` | Что кидается по клику, если выбран «Бросок» | пусто |

*   Поле «Текст» публичное — его можно читать из других виджетов через **Связи**. В формулах текст, состоящий из числа, работает как число.
*   Тогл **«Редактируется игроком»** делает поле доступным только для чтения — удобно для значений, которые собираются формулой.

## Оформление (вкладка «Стили»)
Группы: «Общее», «Текст», «Подпись». Уникальное свойство:
*   **Многострочный** — в однострочном режиме длинный текст уходит за край поля, в многострочном переносится на новую строку.

Остальные свойства — общие: [Оформление виджетов](styling.md).

## Действие по клику
Поддерживается, но по умолчанию выключено. Если включить «Бросок», поле перестаёт быть полем ввода: весь виджет становится кнопкой, и текст правится только через настройки. См. [Действие по клику](../widgets.md#действие-по-клику).

## Примеры
*   Имя персонажа: «Текст» → пусто, подпись → `Имя`, действие по клику → «Нет».
*   Название оружия, которое кидает урон по клику: «Текст» → `Длинный меч`, действие → «Бросок», формула → `1d8 + [str_mod] (Урон)`.

## Частые ошибки
*   **Не получается ввести текст на листе** — включено «Действие по клику»: виджет работает как кнопка. Либо выключен тогл «Редактируется игроком».
*   **Длинный текст обрезается** — включите «Многострочный» и увеличьте высоту виджета.
*   **Вместо текста пусто** — формула в поле ссылается на ненайденную переменную; проверьте алиасы и связи.
