## Материалы из SRD

Веб-сайт longstoryshort.app включает в себя материалы из System Reference Document 5.1 («SRD 5.1») от Wizards of the Coast LLC, доступного по адресу <a href="https://dnd.wizards.com/resources/systems-reference-document" target="_blank" rel="noopener noreferrer nofollow">https://dnd.wizards.com/resources/systems-reference-document</a>.

SRD 5.1 распространяется по лицензии Creative Commons Attribution 4.0 International License, доступной по адресу <a href="https://creativecommons.org/licenses/by/4.0/legalcode" target="_blank" rel="noopener noreferrer nofollow">https://creativecommons.org/licenses/by/4.0/legalcode</a>.
