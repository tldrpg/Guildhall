На этой странице собраны сторонние проекты, которые могут оказаться полезными для пользователей Long Story Shot. Обратите внимание, что мы не несём ответственности за содержание чужих ресурсов и их актуальность.

Если у вас есть инструмент, умеющий работать с Long Story Short, или вы заметили проблему с какой-то из ссылок ниже, расскажите об этом [@shakusky](http://t.me/shakusky) в Telegram.

1. <a href="https://pumpkin.quest/lss/" target="_blank" rel="noopener noreferrer dofollow">PumpkinQuest</a> — веб-сайт с тонной полезностей. <a href="https://pumpkin.quest/lss/dimension-door/" target="_blank" rel="noopener noreferrer dofollow">Dimension Door</a> — браузерное расширение для пополнения Гримуара. <a href="https://pumpkin.quest/lss/dataset-editor/" target="_blank" rel="noopener noreferrer dofollow">Редактор датасетов</a> для нашего конструктора персонажей.
2. [orbrpg.com](https://orbrpg.com/) — веб-сайт, позволяющий находить и организовывать игры (можно отфильтровать по использованию LSS).
3. charbox.org ([5.14e](https://charbox.org/)/[5.24e](https://dnd24.charbox.org/)) — веб-сайт, позволяющий сгенерировать персонажа для D&D (можно затем экспортировать в формате LSS).
4. [GeekDungeonMasterBot](https://t.me/GeekDungeonMasterBot) — Telegram-бот, отвечающий на вопросы о механиках и лоре D&D и позволяющий сгенерировать персонажа для D&D (можно затем экспортировать в формате LSS).
5. [DndMasterWH_Bot](https://t.me/DndMasterWH_Bot) — Telegram-бот, умеющий водить игры и позволяющий сгенерировать персонажа для D&D (в [тестовой версии](https://t.me/WiseHomeAI_bot) можно экспортировать персонажа в формате LSS).
6. [elfrey-lss-converter](https://github.com/Elfrey/elfrey-lss-converter) — модуль для Foundry VTT, позволяющий экспортировать персонажей в формате LSS.
7. [FVTTtoLSSJsonConverter](https://github.com/Pet2022/FVTTtoLSSJsonConverter) — десктопная программа, позволяющая сконвертировать персонажа формата Foundry VTT в формат LSS.
8. [Трекер боя youngdrug6666](https://youngdrug6666-ship-it.github.io/tracker/index.html) — веб-сайт, позволяющий отслеживать сражения персонажей, импортированных из LSS.
