Запись кости — `NdS`: N костей по S граней. Если N не указано, кость одна.

| Запись | Что это |
| --- | --- |
| `1d20`, `d20` | одна двадцатигранная кость |
| `2d6` | две шестигранных |
| `3к8`, `1К12`, `2D4` | то же самое: буква кости — `d`, `D`, `к` или `К` |
| `d%` | процентная кость, то же, что `d100` |
| `dF` | кость Fate: −1, 0, +1 |

Количество и грани можно посчитать: `(ceil([LVL]/2))d6`, `max(1,[WIS])d8`, `1d(6+2)`.
Посчитанное количество округляется вниз; если вышло меньше нуля — костей ноль. `0d6` — ноль костей,
даёт 0.
