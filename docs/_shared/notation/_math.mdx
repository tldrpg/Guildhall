Действия: `+`, `-`, `*`, `/`, `%` (остаток), `^` (степень). Порядок обычный — скобки, степень,
умножение и деление, сложение и вычитание:

*   `1d20 + 5`, `2d6 - 1`
*   `(1d6 + 2) * 2` — скобки работают как в математике
*   `-1d4`, `2 * -1d4` — минус перед костью вычитает её
*   `1d6 / 2` — деление точное, итог броска округляется по правилам игры

Пробелы не важны: `1d20 + 5` — то же, что `1d20+5`. Дробные числа пишутся через точку: `0.5`.
Типографские `−`, `×`, `÷` понимаются как `-`, `*`, `/`.

Функции — имя вплотную к скобке:

| Функция | Что делает | Пример |
| --- | --- | --- |
| `floor`, `ceil`, `round` | округление вниз / вверх / к ближайшему | `floor(4d10/3)` |
| `min`, `max` | меньшее / большее из значений | `max(4d6, 10)`, `min([LVL], 5)` |
| `abs` | модуль | `abs(4d10-25)` |
| `pow`, `sqrt` | степень, корень | `pow(2d6, 2)` |
| `sign`, `exp`, `log`, `sin`, `cos`, `tan` | прочая математика | |
