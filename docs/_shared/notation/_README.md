Общие куски страниц «Нотация формул» листа D&D и Anima — правила записи одни на оба продукта
(общий пакет бросков `@tldrpg/dice`). Файлы с `_` в начале имени не становятся страницами.

Заголовки секций — на страницах продуктов, а не здесь: оглавление справа Starlight строит только
из заголовков самой страницы. Всё, что различается у продуктов (где работают формулы, переменные,
что зависит от системы), — на их страницах.

Источник правил — `storyview/docs/plans/dice-grammar.md`.
