Модификаторы пишутся сразу после кости или группы `{…}` латинскими буквами.

| Запись | Что делает | Пример |
| --- | --- | --- |
| `khN`, `klN` | оставить N старших / младших | `2d20kh1` — с преимуществом, `4d6kh3` |
| `dhN`, `dlN` | отбросить N старших / младших | `4d6dl1` |
| `!` | взрыв: на максимуме добросить ещё кость | `3d6!`, `1d10!>=9` |
| `!!`, `!p` | взрыв в ту же кость; каждый доброс −1 | `2d6!!`, `2d6!p` |
| `r`, `ro` + условие | перебрасывать; `ro` — один раз | `1d20ro=1`, `2d6r<2` |
| `u`, `uo` | перебрасывать повторы | `4d6u` |
| `minN`, `maxN` | грань не ниже / не выше N | `4d6min2`, `4d6max3` |
| `cs`, `cf` + условие | какие грани — критический успех / провал | `1d20cs=20cf=1`, `1d100cs<=5` |
| `sa`, `sd` | отсортировать грани в расшифровке | `4d6sd` |
| условие | подсчёт успехов: итог — сколько костей прошли условие, минус провалы `f…` | `10d10>=8`, `4d6>4f<3` |

Условие — `=`, `!=` (или `<>`), `>`, `<`, `>=`, `<=` и число. Сброшенные кости в логе
приглушены, в сообщениях Vortex и мессенджеров — зачёркнуты.
