Одни и те же правила записи работают везде, где лист бросает кости:

*   [формулы в текстовом редакторе](/doc/text-editor/dice-roller/) — в заметках, умениях, описаниях;
*   урон оружия и бонусы-кости в [системе бонусов](/doc/character-sheet/bonuses/) — например, `+1d4`
    от Благословения;
*   поле формулы дайсницы и «докинуть» в [заряженной дайснице](/doc/character-sheet/advantage-disadvantage/).

В полях, где ждут число, — КЗ, скорость, максимум ресурса — работают
[поля с формулами](/doc/character-sheet/expression-input/). Те же правила записи у
[Anima](/doc/anima/notation/).

## Переменные

Переменные подставляют показатели персонажа. Регистр не важен: `[str]` — то же, что `[STR]`.

| Переменная | Значение |
| --- | --- |
| `[STR]`, `[DEX]`, `[CON]` | модификаторы Силы, Ловкости, Телосложения |
| `[INT]`, `[WIS]`, `[CHA]` | модификаторы Интеллекта, Мудрости, Харизмы |
| `[PROF]` | бонус мастерства |
| `[HALF_PROF]` | половина бонуса мастерства, вниз |
| `[LVL]` | уровень персонажа |

*   `1d8 + [STR]` — урон длинного меча
*   `(ceil([LVL]/2))d6` — кости по уровню
*   `[[STR]+1]d6` — квадратные скобки считаются изнутри наружу; кости внутри них бросаются вместе
    с формулой

Неизвестная переменная — ошибка, формула не бросается.

## Подписи

<Labels />

В бросках листа — урон оружия, кости хитов, формулы в тексте — слова сразу после формулы тоже
подпись, скобки не обязательны: `1к6 колющий`, `1к4/колющий`. Урон из нескольких частей
складывается: `1к4 колющий + 1к6 яд` бросает обе кости, подпись — «колющий, яд». Вид урона из
отдельного поля оружия тоже попадает в подпись броска.

Если слово стоит вместо числа — `1к6 + сила`, — формула не бросится: модификатор пишется
переменной, `1к6 + [STR]`.

## Правила D&D 5e

*   **Крит** — натуральные 20 и 1 на d20 атаки, проверки и спасброска. Крит отмечается, только если
    d20 в броске одна; у урона, костей хитов и зелий крита нет. Явные `cs` / `cf` в формуле важнее.
*   **Преимущество и помеха** — кнопки [заряженной дайсницы](/doc/character-sheet/advantage-disadvantage/):
    бросок превращается в `2d20kh1` / `2d20kl1`. В формуле их тоже можно написать сразу.
*   **Критическое попадание** — опция заряженной дайсницы у урона: кости урона удваиваются, числа нет.
    У заклинания с атакой натуральная 20 включает её для урона сама.
*   **Итог** броска округляется вниз: `1d6/2` при выпавшей 5 даёт 2.
