Разделы документации описывают возможности по отдельности. Здесь — сквозные сценарии: что нажимать по шагам, чтобы получить работающий блок листа.

## Рецепт 1. Характеристика с модификатором и кнопкой проверки

Классическая связка D&D: значение характеристики, автоматически посчитанный модификатор и клик по нему для броска `1d20 + модификатор`. Делается из двух виджетов.

**Шаг 1. Значение характеристики.**
1.  В редакторе шаблона перетащите на холст виджет **«Счётчик (поле)»**.
2.  Откройте его настройки (клик по виджету) → вкладка **Данные**.
3.  «Подпись» → `Сила`, «Текущее значение» → `10`.
4.  Задайте «Текущему значению» **алиас** `str` — по нему на это поле будут ссылаться формулы.
5.  Если максимум не нужен, отключите его в **Стилях** тоглом «Показывать максимум».

**Шаг 2. Модификатор.**
1.  Перетащите виджет **«Модификатор»** рядом.
2.  Вкладка **Связи** → привяжите счётчик «Сила». Без этого переменная `[str]` не найдётся.
3.  Вкладка **Данные** → поле «Модификатор» → впишите формулу `floor(([str] - 10) / 2)`.
4.  Поле «Название» → `Сила`.
5.  В **Стилях** включите «Отображать плюс», чтобы `+2` показывался со знаком.

**Шаг 3. Бросок по клику.**
1.  Там же, на вкладке **Данные**, поле «Действие по клику» уже стоит в значении «Бросок» — у «Модификатора» это поведение по умолчанию.
2.  В поле «Формула броска» впишите `1d20 + [local-modifier] (Проверка Силы)`.
    `[local-modifier]` — собственное поле этого же виджета, привязка для него не нужна. Текст в круглых скобках станет меткой броска в логе.

**Шаг 4. Проверка.** Откройте превью шаблона или лист и кликните по модификатору — в логе появится бросок. Поменяйте «Силу» на `16` — модификатор пересчитается в `+3`, и бросок тоже.

## Рецепт 2. Навык с владением через чекбокс

Бонус мастерства прибавляется к броску, только если отмечено владение навыком.

1.  **Чекбокс** «Владение». Задайте его полю алиас `athletics_prof`. В формулах отмеченный чекбокс равен `1`, снятый — `0`.
2.  **Счётчик (поле)** или **Модификатор** с бонусом мастерства, алиас `prof`.
3.  **Модификатор** «Атлетика»: на вкладке **Связи** привяжите чекбокс, бонус мастерства и модификатор Силы из рецепта 1 (алиас `str_mod`).
4.  Формула броска: `1d20 + [str_mod] + if([athletics_prof] == 1, [prof], 0)`.

Проверить можно прямо в редакторе: рядом с полем формулы показывается предпросмотр вида `среднее (мин–макс)` — он меняется, когда меняются входные значения.

## Рецепт 3. Максимум здоровья по формуле

Счётчик HP, у которого максимум считается сам, а текущее значение ведёт игрок.

1.  **Счётчик (поле)** «Здоровье». Подпись → `HP`, разделитель `/` уже стоит по умолчанию (меняется в **Стилях**).
2.  Вкладка **Связи** → привяжите виджеты с уровнем (алиас `level`) и модификатором Телосложения (алиас `con_mod`).
3.  Поле «Максимальное значение» → `10 + ([con_mod] * [level])`.
4.  Поле «Текущее значение» оставьте числом и убедитесь, что у него включено «Редактируется игроком» — иначе игрок не сможет отмечать урон.

Формулы работают не только в полях броска: любое текстовое или числовое поле виджета умеет считать выражения и подставлять переменные. На этом же держится **«Подпись»**, собирающая текст из чужих значений, — например `Класс защиты: [ac]`.

## Рецепт 4. Бросок, собранный из нескольких виджетов

Когда пул костей или порог успеха складывается из характеристики, навыка и снаряжения, используйте **композицию**: клик по каждому виджету дописывает свою часть, а бросок делается один раз. Пошаговые примеры для Mothership и Forbidden Lands — в разделе [Композиция](/doc/anima/formulas-and-variables/#композиция-бросок-из-нескольких-виджетов).
