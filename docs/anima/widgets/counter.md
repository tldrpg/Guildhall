title: 'Счётчик (поле)'
description: 'Числовое значение с необязательным максимумом: HP, опыт, золото.'
---

Числовое значение, которое игрок правит прямо на листе, — с необязательным максимумом через разделитель: `12/25`. Размер по умолчанию — 3×2 клетки.

## Когда использовать
*   Очки здоровья, опыт, золото, боеприпасы — всё, что меняется по ходу игры.
*   Характеристики, из которых считаются модификаторы.
*   **Чем отличается от «Счётчика (чекбоксы)»**: здесь значение вводится числом, там — отмечается ячейками. Ячейки нагляднее для маленьких запасов (до 10-15), число удобнее для больших.

## Поля (вкладка «Данные»)

| Поле в интерфейсе | Имя в формулах | Что хранит | По умолчанию |
|---|---|---|---|
| Подпись | `local-label` | Название счётчика | `Счётчик` |
| Текущее значение | `local-current` | Число или формула | `0` |
| Максимальное значение | `local-max` | Число или формула | `10` |

*   Оба значения публичные: привязав счётчик через **Связи**, другие виджеты читают их по алиасам. Типовые алиасы — `hp`, `hp_max`, `str`.
*   Максимум может быть формулой: `10 + ([con_mod] * [level])`.
*   Тогл **«Редактируется игроком»** (карандаш рядом с полем) определяет, может ли игрок менять значение на листе. Для «Текущего значения» его обычно оставляют включённым, для «Максимального» — выключают, если оно считается формулой.

## Оформление (вкладка «Стили»)
Группы: «Общее», «Счётчик», «Разделитель», «Подпись». Уникальные свойства:
*   **Показывать максимум** — выключите, если нужен только один показатель.
*   **Разделитель** — символ между текущим и максимальным значением, по умолчанию `/`. Пустое значение убирает разделитель вместе с его отступами.

Остальные свойства — общие: [Оформление виджетов](/doc/anima/widgets/styling/).

## Действие по клику
Не поддерживается: клик по счётчику ставит курсор в поле ввода. Кнопку броска рядом делают [Модификатором](/doc/anima/widgets/mod/) или [Подписью](/doc/anima/widgets/label/).

## Частые ошибки
*   **Игрок не может изменить значение** — у поля выключен тогл «Редактируется игроком».
*   **Формула в максимуме не считается** — виджеты, на которые она ссылается, не привязаны на вкладке «Связи».
*   **Разделитель виден, а максимум — нет** — выключено «Показывать максимум», но разделитель остался непустым.
