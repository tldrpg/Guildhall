Виджеты — это строительные блоки шаблона. Каждый предназначен для своего типа данных или действий. Ниже — что когда брать; подробности по каждому виджету на отдельной странице.

## Виджеты палитры

| Виджет | Когда брать |
|---|---|
| **[Модификатор](/doc/anima/widgets/mod/)** | Числовые бонусы и характеристики, кнопки бросков. Значение считается формулой, а не вводится игроком. |
| **[Текстовое поле](/doc/anima/widgets/input/)** | Любой текст, который вводит игрок: имя, снаряжение, заметки. |
| **[Подпись](/doc/anima/widgets/label/)** | Неизменяемый или вычисляемый текст: заголовки, сводки, текстовые кнопки. |
| **[Чекбокс](/doc/anima/widgets/checkbox/)** | Одно состояние да/нет: владение навыком, статус, наличие предмета. |
| **[Счётчик (поле)](/doc/anima/widgets/counter/)** | Числа, которые меняются в игре: HP, опыт, золото. С необязательным максимумом. |
| **[Счётчик (чекбоксы)](/doc/anima/widgets/counter-dots/)** | То же число, показанное ячейками: заклинания, усталость, удача. |
| **[Контейнер](/doc/anima/widgets/container/)** | Группировка виджетов и раскладка их в ряд или столбец. |

> Прежний виджет **«Текстовый блок»** устарел и убран из палитры: многострочность теперь включается тоглом «Многострочный» в [Текстовом поле](/doc/anima/widgets/input/). Уже созданные «Текстовые блоки» продолжают работать.

Общие для всех виджетов свойства внешнего вида описаны отдельно: [Оформление виджетов](/doc/anima/widgets/styling/).

## Настройки виджета
Клик по виджету в редакторе открывает панель настроек с тремя вкладками:

1.  **Данные** — значения полей, их подписи и служебные тоглы (см. ниже).
2.  **Связи** — какие виджеты привязаны к этому. Без привязки формула не увидит чужую переменную.
3.  **Стили** — внешний вид: [Оформление виджетов](/doc/anima/widgets/styling/).

## Поля и переменные
У каждого виджета свой набор полей — они перечислены на его странице вместе с именами, под которыми поле доступно в формулах. Общие правила:

*   **Собственные поля** доступны без всяких настроек через префикс `local-`: `[local-modifier]`, `[local-current]`.
*   **Чужие поля** видны, только если виджет привязан на вкладке **Связи** *и* поле помечено как **публичное** (иконка глаза рядом с полем, тултип «Публичная переменная»). Приватные поля не видны даже привязанным виджетам.
*   **Алиас** — понятное имя поля для формул: вместо `modifier-663988958975` пишете `[str_mod]`. Задаётся там же, на вкладке «Данные».
*   **Тогл «Редактируется игроком»** (карандаш) определяет, может ли игрок менять поле на листе. Выключенное поле правит только автор шаблона в редакторе.

Подробнее: [Формулы и переменные](/doc/anima/formulas-and-variables/).

## Действие по клику
Любой подходящий виджет можно превратить в кнопку: в режиме игры клик по всей его площади запускает заданное действие. Действие выбирается на вкладке **Данные** параметром **«Действие по клику»**:
*   **Нет** — клик ничего не делает (по умолчанию).
*   **Бросок** — по клику кидается **«Формула броска»**. Формула поддерживает кости, переменные и условия `if()` (см. [Нотация формул](/doc/anima/notation/)).

Под полем формулы переключатель **«Использование дайсницы»** задаёт, что именно происходит по клику:
*   **Бросок** — формула кидается сразу;
*   **Композиция** — клик собирает общий бросок из нескольких виджетов, который кидается один раз (см. [Композиция](/doc/anima/formulas-and-variables/#композиция-бросок-из-нескольких-виджетов)).

Действие по клику доступно виджетам [Текстовое поле](/doc/anima/widgets/input/), [Подпись](/doc/anima/widgets/label/) и [Модификатор](/doc/anima/widgets/mod/). У «Модификатора» бросок по клику включён по умолчанию.

Когда действие включено, весь виджет работает как кнопка — собственная интерактивность содержимого отключается, и значения правятся только через настройки.

Как связать виджеты между собой и заставить значения считаться самостоятельно — в разделе [Формулы и переменные](/doc/anima/formulas-and-variables/).
